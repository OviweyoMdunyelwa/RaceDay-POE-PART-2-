# RaceDay Event Management System – Part 2

## Introduction

RaceDay is an Event Management System developed for managing road running, walking and cycling events. The system allows organisers to manage their events, categories, routes, weather information and results, while participants can register for events and manage their enrolments.

Part 2 builds on the database design and planning that was completed in Part 1. The main focus of this part was to turn the planned system into a working application by developing the API, connecting it to the SQL Server database, adding authentication and role-based access, creating the web application, testing the system and setting up GitHub Actions.

---

## Technologies Used

The following technologies were used to develop the system:

- C#
- .NET 8
- ASP.NET Core Web API
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- xUnit
- Swagger / OpenAPI
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Actions
